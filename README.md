# Nudge

**Nudge** is a gamified todo and productivity app designed to help you stay accountable and turn intentions into action.

Instead of simply reminding you about tasks, Nudge keeps track of your progress, encourages consistency, and gives you a little push when you're trying to postpone things.

## 🎯 Concept

The idea is simple:

> **You decide what you want to do. Nudge makes sure you don't forget.**

Create tasks, schedule when you want to work on them, complete them, earn XP, maintain your streak, and gradually build better habits.

For example:

**English — 14:00–16:00**

Nudge can remind you when it's time to start, check your progress during the planned period, and ask whether you actually completed the task.

## ✨ Planned Features

* 📝 Todo list
* ⏰ Scheduled tasks
* 🔔 Smart reminders and notifications
* ⭐ XP and levels
* 🔥 Daily streaks
* 📊 Productivity statistics
* 🎮 Gamified progress
* 🧠 Behaviour and procrastination insights
* 😈 Optional "hard push" reminder mode
* ⌚ Wear OS companion app
* 📱 Android and iOS support

## 🛠️ Tech Stack

The mobile application is being built with:

* React Native
* Expo
* TypeScript
* Expo Notifications
* Local storage / SQLite
* Zustand

A separate Wear OS companion application will later be developed using:

* Kotlin
* Jetpack Compose
* Wear OS

## 🚧 Status

Nudge is currently an experimental personal project.

The main goal is to explore whether gamification, accountability, scheduled reminders, and behavioural feedback can help make it easier to consistently complete tasks.

The project is also being developed as a practical way to deepen my knowledge of React Native, Expo, Android development, Kotlin, and Wear OS.
